# Portfólio Acadêmico — Catarina Portinho Nauiack

Site estático (HTML/CSS/JS, sem framework) publicado via **GitHub Pages** em
[catarina.portinho.me](https://catarina.portinho.me).

## Estrutura
- `index.html` — página única com as seções Sobre, Formação, Projetos, Publicações, Conteúdo autoral e Contato.
- `style.css` — sistema de design (paleta roxo/nobreza, tipografia, layout responsivo).
- `main.js` — menu mobile, animações de revelação e ano do rodapé.
- `catarina.png` — foto do retrato.
- `CNAME` — domínio customizado (`catarina.portinho.me`).

## Desenvolvimento
Abra `index.html` diretamente no navegador — não há etapa de build.
